# Digital Clock

[Live Demo](https://mim515.github.io/Digital-Clock/)

## Overview
This is a simple, visually appealing digital clock built using **HTML**, **CSS**, and **JavaScript**. It displays the current time with hours, minutes, and seconds in real-time, updating every second. The clock also features smooth animations for a modern look.

## Features
- Real-time time display
- Hours, minutes, and seconds updates dynamically
- Stylish circular progress bars for each time unit
- Fully responsive layout for different screen sizes

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## How to Use
1. Clone the repository or download the ZIP file.
2. Open `index.html` in your preferred browser.
3. The clock will start automatically.
